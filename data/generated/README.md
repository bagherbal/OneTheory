# `data/generated`

## Purpose

This directory is reserved for reproducible outputs generated from code and declared inputs.

## Belongs here

Later artifacts may include exact certificates, numerical convergence records, state trajectories, manifests, and comparison reports whose generating command and input hashes are recorded.

## Does not belong here

Hand-edited source inputs, fitted physical constants, observations, hidden defaults, or outputs treated as geometry or vacuum selectors do not belong here.

## Dependencies

Generated artifacts are downstream products. They may be consumed by verification or later declared computations, but they must never become hidden source inputs or create a reverse dependency into research.

## Promotion condition

A generated artifact may be retained as a reviewed result only when its code version, inputs, environment, command, exact or numerical status, convergence evidence where applicable, and integrity hash are reproducible.
