# Computable carrier artifacts

This directory stores deterministic outputs from
`research/experiments/computable_carrier`. The artifact is for the new
OneTheory construction and is never the published reference carrier.

Every JSON artifact is content-addressed over canonical exact metadata. The
current artifact freezes the target contract and finite Tier A/B/C search
frontier; it does not claim a selected bundle. Until chain-level, equivariance,
local-freeness, stability, spectrum, DGA, metric, instanton, anomaly, and
independent external-algebra gates pass, production imports remain forbidden.

Generated outputs must be reproducible from declared code and inputs. They must
not be used as hidden source inputs or populated with measured observables,
random coefficients, generic maps, or copied reference-carrier cocycles.
