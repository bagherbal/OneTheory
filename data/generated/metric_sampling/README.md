# Metric sampling artifacts

`leverage_diagnosis.json` is the content-addressed output of
`research/experiments/metric_sampling/leverage.py`. It records the exact
leverage identity, effective training size, in-sample/out-of-sample curvature
split and the registered prediction for the 8192-point training population,
pinned to the SHA-256 of every source artifact. It is not a metric and no
observation entered it.
