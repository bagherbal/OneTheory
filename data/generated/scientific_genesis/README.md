# Scientific Genesis state artifacts

This directory stores deterministic, machine-readable audits generated by
`research.experiments.scientific_genesis`. The state binds epistemic claims,
dependency edges, reusable machinery, artifact hashes, unresolved gates,
structural questions, and research priorities to the repository evidence that
supports them.

The artifact is governance data, not a physical result. It may report that an
implementation exists without calling its scientific output established, and
it must preserve blocked prerequisites rather than inventing bridge objects or
fallback values. Observations remain terminal comparison data.

Production code must not import this directory. Research may consume the state
to choose calculations that close meaningful dependency edges. Regeneration
must be deterministic, validate the graph as acyclic, require exactly one
allowed epistemic status per claim, and verify all evidence paths.

Promotion of any referenced research result still requires an explicit
mathematical statement, assumptions, exact or controlled computation,
content-addressed evidence, independent critical verification, scientific
review, and tests in its true production domain.
