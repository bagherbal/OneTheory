# Generated visible-carrier artifacts

Exact outputs reconstructed from the frozen published source manifest belong in
this directory. Each artifact must be canonicalized, content-addressed, and
accompanied by its generating command, software versions, input hashes, basis
ordering, and exact verification results.

No generated artifact may silently become a source input. An artifact that
contains only a dimension count or a metadata ledger must state that it is not a
chain-level representative and must not unlock downstream physical code.
