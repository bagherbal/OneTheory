# Published visible-carrier sources

This directory freezes provenance for the one-Higgs observable (SU(4)) carrier.
The manifest records the exact arXiv source and PDF digests used for the
reconstruction, together with equation labels and source line locators.

The canonical sources are the v3 one-Higgs spectrum paper, the stability paper,
and the Schoen (\mathbb Z_3\times\mathbb Z_3) geometry paper. The older
two-Higgs construction is explicitly excluded. These files are immutable
published inputs; generated certificates and reconstructed exact outputs belong
under `data/generated/visible_carrier/`.

Promotion requires matching source and PDF hashes, a recorded source locator,
an exact transcription, and an independent verification of every promoted
identity.
