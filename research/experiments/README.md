# `research/experiments`

## Purpose

This is the only active location for unresolved OneTheory investigations during Phase 0 and later development.

## Belongs here

Exploratory derivations for open visible-sector rank lifting, metrics, instanton determinant lines, hidden bundles, vacuum stabilization, observables, and the native-origin theorem belong here while their inputs or certificates are incomplete.

## Does not belong here

Promoted production algorithms, guessed physical objects, synthetic fixtures reported as results, bridge abstractions, or a permanent parallel implementation of production code do not belong here.

## Dependencies

Experiments may import production modules and may consume published inputs. The production package must never import this directory, its modules, or its artifacts.

## Promotion condition

Promotion requires a reproducible result, independent certificate, scientific review, correct placement in the owning production module, tests, and removal or reduction of the active experiment to a thin reproducer outside the runtime path.
