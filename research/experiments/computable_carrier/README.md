# Computable carrier genesis

This experiment defines and searches a new OneTheory visible-carrier category.
It is deliberately separate from the published one-Higgs reference carrier:
sharing Schoen geometry or point-scheme architecture does not establish bundle
identity.

The experiment owns the immutable construction contract, finite Tier A/B/C
bounds, exact candidate descriptors, chain-level artifacts, independent
verification manifests, and promotion gates. It may import reusable
production mathematics and the reference carrier only as benchmark data. It
must never import observations, use measured quantities, or turn a reference
dimension count into a new cocycle.

Tier A is the first active search. Tier B is available only after Tier A is
certified empty, and Tier C is locked until both earlier tiers have their own
scoped no-go certificates. Every generated object carries a status and digest;
an incomplete descriptor cannot be promoted into `src/onetheory`.
