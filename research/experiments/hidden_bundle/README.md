# `hidden_bundle`

## Purpose

This experiment audits the bounded objective-(28) hidden-bundle search and the
exact inputs required to promote a primitive rank-two bundle into a descended
stable hidden (SU(4)) bundle.

## Belongs here

The 44 support records, candidate-750 polynomial maps, multigraded charts,
equivariant linearizations, Fitting-ideal calculations, extension classes,
curve restrictions, stability certificates, and spectrum computations belong
here until independently certified.

## Does not belong here

Sampled ranks, Chern targets, invariant supports, one slope inequality, an
assumed pure (Spin(10)) theory, or an unproved candidate do not count as a
physical bundle and must not be promoted as one.

## Dependencies

The experiment may inspect exact production topology, geometry, visible data,
and declared published manifests. Production must never import this experiment
or consume its candidate artifacts as hidden runtime inputs.

## Promotion condition

Promotion requires complete support and matrix inputs, global local-freeness,
honest equivariant descent, a non-split extension, all curve restrictions,
stability in a common chamber, and an exact hidden spectrum.
