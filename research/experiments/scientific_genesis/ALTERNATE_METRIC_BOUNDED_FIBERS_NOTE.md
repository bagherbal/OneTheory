# Bounded universal quotient frames

The geometric enclosure prerequisite bounds actual cover charts and local
coefficients. This successor carries those bounds through the **same**
nine-generator/five-relation universal bundle presentation. Both extension
parameters remain symbolic. A frame is accepted only on a declared pivot
domain whose determinant enclosures exclude zero. No global atlas coverage,
complete bounded section matrix, sample law, or metric is asserted.

Exact `Matrix` arithmetic accepts Rational/Eisenstein fields, not enclosure

external dependency is introduced. Two- and three-row pivot inverses use

This code uses the elementary small adjugate identity rather than FLINT's
verified linear-system algorithms. A rejection means that this frame or
precision did not certify inversion; it is not a physical no-go. There is
no automatic pivot search, chart change, precision increase, or fallback.

## Universal elimination theorem

Let B1 be the actual 4-by-2 constituent relation matrix and B2 the actual
5-by-3 matrix. Let E(a)=a0*E0+a1*E1 be the actual 4-by-3 outer coefficient.
The entire boundary is

```text
B(a) = [ B1  E(a) ]
       [  0   B2  ].
```

For each explicitly selected row tuple, let Ri select pivot rows and Fi
select the complementary generator rows in their original order. Set

```text
Mi = Ri*Bi,
Si = inverse(Mi)*Ri,
Pi = Fi - Fi*Bi*Si.
```

Nonzero determinant gives Si*Bi=I and Pi*Bi=0. Let Ji include the free
generator columns; Ri*Ji=0 and Fi*Ji=I give Pi*Ji=I and Si*Ji=0. Hence

```text
Q(a) = [ P1  -P1*E(a)*S2 ]
       [  0       P2      ],
J = diag(J1,J2),
Q(a)*B(a)=0,
Q(a)*J=I4.
```

These are exact identities on the certified pivot domain, not claims
inferred from interval residuals containing zero. The selected five-row
boundary minor is block triangular. Its determinant is det(M1)*det(M2),
independent of a0,a1. Thus the frame is valid throughout the universal
parameter family on this geometric domain; it does not select a physical
extension point or make the excluded split origin lawful.

For the original section's ambient coefficients

```text
v(a) = (v1 + a0*b0 + a1*b1, v2),
```

the fiber coefficients are

```text
constant: (P1*v1, P2*v2),
a_i:      (P1*b_i - P1*E_i*S2*v2, 0).
```

No quadratic terms occur because parameter projections only act on the
second constituent, while parameter section corrections occupy the first.
The implementation bounds the original universal cochains on demand,
including their full outer corrections. It does not replace v(a) by a
direct sum or select either parameter. Frame transitions Q_other*J_self
use the identical certified point and chart; the quotient identities give
their inverse and cocycle laws.
