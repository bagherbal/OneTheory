# Complete bounded output on a declared local domain

The next open edge is actual complete output of the existing bounded
all-index evaluator. This experiment does not change that evaluator,
the carrier, its 5,345-section basis, the outer lifting series, the
symbolic extension parameters, or any normalization convention.

## Why execute this gate now

At the finite regression domain, the first outer column cost about
72 seconds after frame setup. The following nine original indices cost
approximately 0.1 seconds each, reusing exactly the same 36 correction
units and 4,707 original perturbation columns. The latter are columns
compiled from actual exact operators, not fitted response functions.

A static scan of the actual V2 stream finds 1,972 source correction keys.
Factoring the coordinatewise common regular monomial using actual arrow
minima would reduce that count to 1,477 per parameter. That is a possible
optimization, not an implemented theorem or a promise of practical
throughput. It does not justify replacing the verified evaluator before
measuring the entire required output. The governing dependency edge
already requires complete bounded output and measured multi-point cost.

## Input and output contracts

The input is explicitly the predecessor `finite_chart` configuration,
root pair `(0,0)`, homogeneous pivots `(0,0,0)`, constituent pivot rows
`(0,2)` and `(0,1,2)`, and 80-bit outward radius mesh. Its actual-cover
membership comes from the original complete projective-root certificates.
Centers do not become exact `CoverPoint` objects. This is a declared
regression domain, not a selected bundle/vacuum modulus or an SU-uniform
probability draw.

The writer calls the existing evaluator at every integer index from zero
through 5,344, without skipping or filling columns. Each JSON-line record
contains its original index and all three four-by-one coefficient columns
in the order constant, `a0`, `a1`. Circular centers and radii remain exact
rational data; uncertain zeros are retained by the original engine.

The compressed stream has fixed gzip timestamp and filename metadata.
The writer then reads every column through a separate parser, checking
ordering, completeness, dimensions, exact radius mesh, and the zero
extension coefficients of injected V1 sections. It records compressed
and uncompressed SHA-256 hashes, byte count, coefficient-entry count,
uncertain-entry count, and largest radius. Those summaries measure the
stored enclosures; they do not assert a requested relative accuracy.

Only a completely evaluated and validated stream is installed. Different
existing scientific outputs are not overwritten. Temporary partial streams
are not certified artifacts. Format tests use actual predecessor probes,
reject truncation and malformed coefficients, and never replace full
execution with a synthetic matrix or mocked count.

## Verification scope and unresolved physics

Archive parsing verifies completeness and encoding, not the scientific
section algorithm. The latter retains its original operator-naturality,
filtration, independent exact point archive, off-center full original
cochain, and Gaussian-elimination checks. The new packet explicitly does
not claim an independent full-cochain replay of every column. Successful
execution must still be audited with its actual hashes before the state
marks the complete-matrix gate computed.

One complete matrix on a single certified local domain is not global atlas
coverage, measured practical multi-point throughput, a controlled proposal
law, integration-error control, Ricci-flat/HYM convergence, harmonic matter
metrics, or a common stabilized vacuum. It supplies none of the remaining
holomorphic flavor sectors and does not derive Genesis-to-UV. Physical
Yukawa, sampling, metric, moduli-selection, and observational-input flags
remain false.
