# Alternate ray stability: theorem-scope check

This note concerns the locally free I6 ray with source characters `(0,1)`,
not the source-selected I6 ray. The exact universal outer cone has invariant
parameter space `P¹(Q(omega))`; every point is a nonzero class in
`Ext¹(V2,V1)` and therefore defines a non-split extension. The common
character twist `(1,2)` repairs the quotient determinant and is flat, so it
does not change any slope.

The [published stability proof](https://arxiv.org/pdf/hep-th/0602073),
especially its Serre sequences (46a,b), sub-line analysis (25–31), and
Proposition 1 (32), bounds destabilizing line classes using the subline and
fixed ideal quotient of each rank-two Serre bundle. For a line map into a
constituent, composition with the ideal quotient either vanishes, forcing
the map through the Serre subline, or gives a line map into that quotient.
The latter must vanish on the same I3 or I6 scheme. These possible largest
slopes depend on the two line degrees and ideal supports, not on coordinates
of the nonzero Serre extension class. The argument excludes a splitting;
the alternate ray has exact nonzero local units at all I6 support points.

The [extension stability bound](https://arxiv.org/pdf/hep-th/0512205),
§2.1, filters a subobject of the rank-four extension through subobjects of
its two constituents. It excludes the `(0,V2)` case precisely when the outer
extension is non-split. Both constituent presentation types are unchanged
for the alternate ray, and the exact invariant basis makes every nonzero
`P¹` parameter non-split. Thus the same nine sufficient slope inequalities
apply to the full alternate family. Exact rational evaluation of the
published open-box witness proves a nonempty Kähler chamber; it does not
classify every stable Kähler class.

On that chamber the descended determinant-trivial bundle is stable. The
unchanged graded line-object K-class gives the same nonzero cover `c₃`; on
the simply connected cover, stable irreducibility together with this odd
Chern class excludes proper connected irreducible reductions. This is a
source-scoped sufficient theorem, not a physical-spectrum computation.
Matter and Higgs cocycles for this alternate family remain to be generated.
