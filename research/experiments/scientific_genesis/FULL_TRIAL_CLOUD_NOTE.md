# Original-basis trial integration beyond the pilot rank bound

## Decisive question

Can a sufficient independent cloud at the same selected, unstabilized point
`(1, omega)` support the first actual inverse-based metric update in the original
5,345-dimensional section space? The sixteen-sample pilot has rank at most 64.
Its numerical error is now bounded, but it cannot answer this question.

The next workload is fixed before evaluating geometry: 1,536 training samples
and 512 separately identified validation samples. These are engineering sample
budgets, not physical constants. Training crosses the necessary 1,337-sample
rank-count threshold; it does not guarantee an invertible or accurate operator.
Validation is not used to select geometry or modify the training population.

As a cheap necessary check before the new inputs are captured, the already
derived four-sector common rank-three polynomial evaluates at `(1, omega)` to
`-9/87808 + 81/43904*omega`, which is nonzero in Q(omega). The pilot point is
therefore not on that known rank-loss locus. This exact algebraic check is not
a hierarchy prediction, stability proof, metric or vacuum selection.

Every input retains all thirteen named streams, the original auxiliary measure,
the complete original section identity, unit H0, residue scale one, covering
degree nine, original chart and quotient pivots. New public OS bytes supply a
new declared workload, not replacement draws for failed pilot samples. The
pilot inputs, discoveries and integer certificates remain frozen.

## Execution and retention

The sampler captures the entire training/validation packet before any outcomes
are known. Fair independent infinite streams remain **ASSUMED**, not proved by
finite Linux getrandom receipts. Component and branch selection are unchanged.
Workers own disjoint original ordinals. Changing scheduling cannot change the
scientific request or introduce fresh entropy.

Each sample begins at level 16. Only if its native frame or numerical kernel is
unresolved is that same address refined to level 20, then 24. This is a precision
policy, not conditioning the measure on easier points. Every history retains
the original streams, all native root families, original branch, named frame,
input cells, row preconditioner and numerical precision. Work exhaustion or
binary64 rank failure retains an explicit unresolved checkpoint.

The frozen polynomial instructions are compiled once per worker. They evaluate
every original section; the four full numerical row factors contain all 5,345
coordinates. A checkpoint is immutable. Restarting a terminal worker reuses its
completed checkpoints, including failures, rather than redrawing any sample.
Active workers must be observed through their actual process handles, not
restarted merely because a progress query returns no output.

No admitted-subset integral is computed. Aggregation requires every requested
checkpoint. An unresolved member prevents availability of the full workload.
The collector installs only a source-bound manifest, not an operator or metric.
The numerical solver must consume all training inputs and separately retain the
validation population before making any global or convergence claim.

## Solver boundary

The published generalized bundle update is an inverse T-operator iteration;
see [Anderson, Braun and Ovrut](https://arxiv.org/html/1103.3041), equations
(3.19), (3.22) and Table 1. A finite-cloud update is still an approximation.
Convergence at one twist does not establish HYM convergence or physical flavor.

The pilot diagonal entries span approximately `3.2e16`. This is a warning about
the original numerical coordinate scale, not a condition-number estimate for a
full-rank global operator. Any diagonal equilibration must be declared as an
invertible solver congruence, retain all coordinates and return the form in the
original basis. It must not replace the unit initializer by a fitted form.
No ridge, pseudoinverse, truncated singular subspace or reduced section basis
is permitted to manufacture an update.

Possible outcomes are an admitted full-basis numerical step, unresolved span,
or an explicit precision/conditioning obstruction. The first moves to further
iteration and independent validation. The others determine the next numerical
requirement; neither licenses pretending that a smaller section system solves
the original problem. Numerical uncertainty, statistical uncertainty and the
fair-stream assumption must remain separate. Matter/Higgs metrics, physical
Yukawas, a stabilized vacuum and Genesis-to-UV derivation remain unavailable.
