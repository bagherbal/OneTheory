# Retained independent inputs and the first global trial operator

## Scientific question and fixed experiment

Can the frozen original section system be evaluated on a new auxiliary cloud,
rather than only on the old regression domains, while preserving difficult
samples? The workload is fixed before geometric outcomes: sixteen retained
samples, thirteen named streams of 128 bits each, two refinement levels 12 and
16, and a 65,536-cell work cap per root admission. The original line frames,
chart `(0,0,0)`, fiber pivots `(0,2)` and `(0,1,2)`, unit residue scale, and
ninefold covering degree are explicit. The exact parameters `(1, omega)` are a
selected computational point, not a stabilized vacuum or an observational fit.

All entropy bytes have already been captured in `independent_cloud_inputs.json`.
They must not be regenerated when admission, precision, or evaluation fails.
The Linux `os.getrandom` source has no user seed; short reads are concatenated
from that same source. Its documented interface is described in the
[Python 3.12 OS reference](https://docs.python.org/3.12/library/os.html#os.getrandom).
The law of mutually independent fair infinite named bit streams is **ASSUMED**.
Neither finite receipts nor this OS interface prove IID. Duplicate byte values
are retained; rejecting them would condition the input law.

3/4, 1/8, 1/8 from three component bits. Existing projective address maps consume
spacing and phase bits. Uniform ternary root selectors reject the bit pair 11

Existing native subdivision certifies complete projective root families. The

any requested sample at that level is unavailable: no admitted-subset average.

## Full operator without a dense section-space matrix

At each admitted frame, the frozen sparse evaluator supplies all 5,345 original
sections in all three coefficient channels. Combining the explicit parameters
gives four rows of S. Two-pass modified Gram--Schmidt constructs Q with
`Q Q† = I4`; the explicit four-by-four row transition is recorded. In exact
arithmetic the unit-H kernel is

`P = S† (S S†)^(-1) S = Q† Q`.

This row preconditioning is not a physical field normalization. Binary64
orthogonality and relative independence tolerances are declared engineering
policies. Input radii and floating-point roundoff are not bounded by this
discovery evaluator. Its centers are not claimed to be exact cover points.

The empirical global operator is `Abar = sum(w_i Q_i† Q_i)/n`, with the actual
positive quotient weights from the established beta-cubed/72 auxiliary law.
The common factor pi-cubed is explicitly omitted. Full rows, all diagonal
entries, trace, and Frobenius norm are retained. Cross-projector overlaps use
the four-by-four cross Gram matrix: `tr(P_i P_j) = ||Q_i Q_j†||_F^2`.
This evaluates the entire operator, not selected probes or a reduced section
model. Its rank is at most `min(5345,4n)`. At least 1,337 samples are necessary,
not sufficient, for invertibility. No inverse, ridge, pseudoinverse, reduced
basis metric, or invented H1 is supplied for this sixteen-sample cloud.

## Honest uncertainty boundary

The unchanged global conormal certificate gives a positive exact lower bound
delta and the ideal quotient weight bound `0 <= w <= B = (12/9)/delta` at unit
residue scale. An ideal rank-four projector has Frobenius norm two. Conditional
on the fair IID law and exact kernels, the Hilbert-space variance identity gives
`E ||Abar - E A||_F^2 <= 4 B^2/n`. Markov's inequality therefore bounds the
failure probability by alpha at squared radius `4 B^2/(n alpha)`. This very
conservative bound applies to the actual positive law; it is not borrowed from
an obsolete infinite-variance proposal. It does **not** cover discovery
arithmetic or input-cell error. Empirical standard errors and same-sample
refinement differences are diagnostics, not confidence or numerical error
certificates. Raw squared refinement differences are retained even if floating
cancellation makes them slightly negative; they are not silently clamped.

Thus even a successfully executed cloud supplies only a conditional discovery
estimate, not a controlled global integral, nonunit-H iteration, converged HYM
solution, matter/Higgs metric, physical Yukawa matrix, or common vacuum. The
next calculation must address this error and rank boundary without discarding
the original samples or replacing the original section system.
