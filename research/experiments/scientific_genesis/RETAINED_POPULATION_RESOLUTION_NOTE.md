# Full retained-population numerical resolution comparison

The old empirical H1 trace estimate is inconsistent with its conditional
continuum interpretation. Native same-input checks showed substantial coarse
root-resolution sensitivity, but did not explain every large-curvature point.
The next scientific question is whether that sensitivity changes the complete
old-population curvature profile, keeping the original H1 fixed.

The experiment preserves all 2048 original inputs, their 1536/512 split, named
streams, saved root indexing, original chart and pivot rows, scale, degree and
5345 sections. It obtains no new entropy. Each spacing/phase input uses the
midpoint of its first 128 captured bits. Exact rational spacing subtraction
precedes conversion, so floating-point ties do not erase a spacing. The input
formula is unchanged; this is a finer numerical representative, not the ideal
infinite-stream point.

Each saved root center seeds eight binary64 Newton steps in its saved parameter
chart. No root sorting, nearest-root selection, reseeding or fallback occurs.
An exact rational comparison proves only that the resulting floating candidate
lies within the original root disk. Residuals of the actual binary cubic and
cover equations must satisfy the declared scaled 1e-12 policy. These are
discovery checks: they do not certify the new root, its input accuracy or cover
membership. Binary64 coordinates generally cannot lie inside a 128-bit source
input enclosure. Independent native checks remain a separate requirement.
The whole-population request requires the retained outcomes of all four
predeclared native checks (17, 101, 1819, 1980) and pins their digests. It cannot
start if any comparison is unavailable, unresolved or source-incompatible.

The full original section/first-jet and H1 consumers are reused. The unchanged
derived conormal weight includes explicit scale and quotient degree; pi cubed
is restored only in the same reference-background formula. Weights are not
calibrated to volume or Chern-Weil targets. No H1 rebuild or H2 is executed.

Separate immutable output files retain every original outcome. A failed sample
is not replaced and a complete manifest is unavailable until all 2048 outputs
exist. Any unresolved evaluation forbids every aggregate. Old inspected
validation stays labeled inspected, not blind. A complete numerical mean is
COMPUTED discovery evidence, not a controlled continuum integral, HYM solution,
matter metric, canonical Yukawa or common vacuum. Independent certification
checks, arithmetic/input bounds and useful statistical control remain open.
