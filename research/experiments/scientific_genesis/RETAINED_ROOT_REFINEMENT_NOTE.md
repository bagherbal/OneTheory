# Retained-root acceleration and its scientific boundary

The complete old H1 curvature profile fails the conditional continuum trace
constraint. Same-input sensitivity exposed inadequate coarse input resolution,
while one large-curvature point remained large after refinement. A controlled
whole-population operator therefore needs an input-resolution policy; another
local precision ladder is not the target.

The existing native root and frame theories are sufficient. This consumer
restores saved subdivision certificates literally against the actual captured
input cells, rather than searching their roots again. A depth-k square midpoint
in the original [-2,2]^2 atlas has odd coordinate numerators over 2^(k-1).
Recovering k reproduces the original modulus_bits+k Taylor convention; every
saved coefficient, radius, error bound and strict margin must then agree.

For finer versions of those same captured streams, each parent disk supplies a
seed in its existing parameter chart. Exact Newton iterates are rounded onto
the caller's declared (1,omega) mesh. An explicit separate step cap bounds work.
Acceptance requires the original positive-radius Rouche witness, uncertainty
margin, three-root completeness, projective disjointness and strict native
parent-containment bijection. Small residuals, nearest-center matching, reseeding
and automatic subdivision fallback are not acceptance rules. Failure retains
the same pending input and admitted parent.

The benchmark uses only post-selected ordinals 526 and 1360, at levels 16 and
32, with eight Newton steps permitted. Coarse geometry must replay literally;
finer families are checked against the independently executed native packets
using common-parent ancestry. The original named frame, scale, degree, all 5345
sections and full H1 factor remain unchanged. Results and timings are discovery
evidence, not error bounds, an IID sample or a repaired global mean. No old
checkpoint is replaced and no H2 is run.

If exact restrictions and frame admission still dominate, use this consumer as
the certification path for independent checks of faster numerical discovery.
Do not require every global discovery point to redo every exact proof. A global
resolution/error policy, useful sampling control and actual metric convergence
remain required before derived matter metrics or canonical Yukawas.
