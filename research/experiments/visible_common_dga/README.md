# `visible_common_dga`

## Purpose

This experiment audits whether the carrier-specific common Čech–Koszul/DGA
inputs required by the visible-sector (f_3) trace computation are present.
It is the active reconstruction boundary for the physical rank-lift problem.

## Belongs here

Input manifests, byte-level sufficiency checks, exact reconstruction attempts,
and reproducible reports for the synchronized (V_1/V_2) complex, external
hypercocycles, restricted actions, contractions, pairings, and trace words
belong here until independently certified.

## Does not belong here

Synthetic carrier matrices, guessed representatives, fitted residues,
observation-driven choices, speculative bridges, or a second production
implementation do not belong here. The experiment must not label dimensions
or expected outputs as computational inputs.

## Dependencies

The audit may inspect declared production contracts and published manifests.
Production code must never import this experiment or consume its reports as
hidden runtime inputs.

## Promotion condition

Promotion requires every required serialized or directly derivable object,
exact identities and certificates for the common complex, scientific review,
and production tests. Until then the earliest missing object remains explicit.
